# SixFlow Plugin Marketplace

Private plugin marketplace for SixFlow clients. Install AI assistants built for your
business directly inside Claude Cowork - no file downloads.

## Available plugins

- **sixflow-law-firm-ops** - AI operations assistant for law firms: an automatic morning
  brief (today's schedule + prioritized inbox digest, emailed to your team), on-demand
  inbox digests, and legal document review.

## How to install (for clients)

In Claude Cowork, an admin adds this marketplace once, then installs the plugin:

```
/plugin marketplace add sixflow-ai/claude-law-agent
/plugin install sixflow-law-firm-ops@sixflow
```

Then run `/onboarding` to connect your tools and tailor it to your firm.
